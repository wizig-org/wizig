# `src/cli/commands/codegen/render/android_jni/base_sections.zig`

_Language: Zig_

Shared C/JNI sections emitted before method-specific JNI bridge exports.

Contains: Android stdio forwarding, error helpers, stack-optimised
`new_jstring_from_bytes`, symbol validation, and ABI compatibility check.

## Public API

### `appendBaseSections` (fn)

Appends shared C helper functions and the `wizig_validate_bindings`
JNI entry-point to `out`.  These are emitted once, before the
per-method exports generated by `method_exports.zig`.
